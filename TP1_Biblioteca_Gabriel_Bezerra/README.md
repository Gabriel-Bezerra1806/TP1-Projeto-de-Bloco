## Como executar
1. Instale o JDK 21.
2. Abra a pasta do projeto no IntelliJ IDEA Community Edition.
3. Configure o Project SDK como JDK 21.
4. Execute a classe `Main`.

Também é possível compilar e executar pelo terminal, dentro da pasta do projeto:
```bash
javac -d out src/Main.java
java -cp out Main
```

## Limitações intencionais do protótipo
Este é um exercício de lógica inicial, não o sistema completo. Os dados são temporários, não há banco de dados e não há classes de domínio. A multa de R$ 2,00 por dia é apenas ilustrativa e precisa ser confirmada com o professor.
